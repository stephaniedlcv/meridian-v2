Height:
- Default UI input should be ft + in.
- Example fields:
  Feet: [ 5 ]
  Inches: [ 4 ]
- Also provide a small unit toggle:
  ft/in | cm
- If user chooses cm, show a single cm input.
- Always save internally as height_cm.
- If blank or invalid, save null.
- Do NOT require the user to convert manually.

Weight:
- Default UI input should be lbs.
- Example:
  Weight: [ 151 ] lbs
- Also provide a small unit toggle:
  lbs | kg
- If user chooses kg, show kg input.
- Always save internally as weight_kg.
- If blank or invalid, save null.
- Do NOT require the user to convert manually.

Conversion:
- height_cm = (feet * 12 + inches) * 2.54
- weight_kg = pounds / 2.2046226218
- Round stored values to 1 decimal place.
- Display values rounded cleanly.

Training days:
- Accept integer 0–7.
- If invalid or blank, save null.
- Do not block saving.
