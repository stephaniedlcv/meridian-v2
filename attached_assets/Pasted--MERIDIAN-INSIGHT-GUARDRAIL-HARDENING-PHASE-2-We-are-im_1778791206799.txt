If the AI mentions a biomarker not present in the input JSON, the route logs/appends a warning to logic_trace but still returns the insight.

2. Forbidden word guard currently replaces forbidden words with "***":
This can render broken copy to the user.

PRODUCT RULE:
Never show:
- hallucinated biomarker references
- diagnostic/forbidden language
- text with "***"
- broken AI cleanup artifacts

If an insight fails these guardrails, return:

insight: null

Dashboard already handles insight_unavailable gracefully.
