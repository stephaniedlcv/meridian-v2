MERIDIAN — COHERENCE HARDENING SPRINT A
(HISTORY PARITY + FILTER SYSTEM + CANONICAL EXPLANATION UNIFICATION)

This sprint is NOT about adding new features.

This is a coherence hardening sprint focused on:
- trust
- consistency
- architectural maturity
- emotional continuity
- intelligence-system cohesion

The audit identified several places where Meridian stops feeling like:
“one coherent intelligence system”
and instead feels like disconnected UI layers.

This sprint fixes the highest-impact coherence gaps before family/private beta.

- redesign layouts
- change range math
- modify state engine logic
- modify ingestion
- modify database schema
- add wearable integrations
- add predictive features
- rewrite AI systems
- alter visual identity

This sprint is:
CONSISTENCY + PARITY + ARCHITECTURAL CLEANUP ONLY.

- BIOMARKER_CONTEXT
- INTERPRETATIONS
- HIST_INTERPRETATIONS

3. generic fallback only if absolutely necessary
