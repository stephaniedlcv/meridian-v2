4. OCR/PDF artifacts should not appear as normal pending biomarkers.

Observed examples:
- A1C-W2
- HB-W2

These appear to be PDF/OCR artifacts or worksheet codes, not clinical biomarkers.

If an extracted item looks like a worksheet code, OCR residue, calculation artifact, or document artifact:
- do not count it as a marker found
- do not include it in confirm/save payload
- do not display it as a normal pending biomarker
- if shown, place under a smaller section called:
  Possible document artifacts
- allow Ignore if existing ignore behavior supports it
- use calm language, not red/alarming language

5. Numeric validation guardrail

Only run numeric physical range validation when:
- the marker is expected to be numeric
- parsed value is a finite number

If marker is qualitative:
- do not run numeric physical range validation
- do not show “Value null...” error

If a numeric marker has no readable value:
show:
“Value could not be read.”
not:
“Value null is outside physically possible range.”

Do not save null numeric values.

6. Urinalysis qualitative handling

Recognize common Urinalysis markers as Urinalysis context:
- Color
- Appearance
- Specific Gravity
- pH
- Urine Glucose / Glucose, urine
- Urine Protein / Protein, urine
- Ketones / Acetone
- Blood
- Nitrite
- Leukocyte Esterase
- Urobilinogen
- Bilirubin, urine
- RBC / Red Blood Cells
- WBC / White Blood Cells
- Epithelial Cells
- Bacteria
- Mucus
- Crystals
- Casts

Supported qualitative values:
- Negative
- Normal
- Clear
- Yellow
- None Seen
- Trace
- Few
- Moderate
- Large

Do not confuse:
- serum glucose with urine glucose
- CBC WBC/RBC with urine sediment WBC/RBC

Use panel context, marker name, unit, reference text, and surrounding extracted data when available.

If qualitative markers cannot be safely saved due to numeric-only schema:
- keep them out of numeric save payload
- do not insert null values
- show them as qualitative urinalysis markers or pending qualitative markers
- make clear they will not affect numeric lab counts/signals yet
