# T003 — Duplicate Biomarker Resolution

Implement canonical duplicate merge strategy.

Priority:
1. valid PDF range
2. non-null value
3. newest extraction timestamp
4. canonical-compatible unit

Reject:
- corrupt ranges
- impossible values
- malformed duplicate rows

No duplicate AST/RBC/etc rows should render simultaneously inside the same snapshot unless truly distinct measurements exist.
