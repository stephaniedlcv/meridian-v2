REAL TESTING ISSUES FOUND:

1. Urinalysis qualitative markers are still problematic.

Observed examples:
- Color: Yellow
- Appearance: Clear
- Acetone
- Specific Gravity: 1.015
- Urobilinogen
- Nitrite
- Epithelial Cells
- RBC / Red Blood Cells in urine
- WBC / White Blood Cells in urine

Problem:
These are being treated like regular numeric serum biomarkers or sent to Pending Classification without enough context.

Expected:

4. OCR/PDF artifacts should not appear as normal pending biomarkers.

Observed examples:
- A1C-W2
- HB-W2

These appear to be PDF/OCR artifacts or worksheet codes, not clinical biomarkers.

If an extracted item looks like a worksheet code, OCR residue, calculation artifact, or document artifact:
- do not count it as marker found
- do not include it in confirm/save payload
- do not display it as a normal pending biomarker
- if shown, place under a smaller section:
  Possible document artifacts
- allow Ignore if existing ignore behavior supports it
- use calm language
- do not use red/alarming language

5. Numeric validation guardrail

Only run numeric physical range validation when:
- the marker is expected to be numeric
- parsed value is a finite number

If marker is qualitative:
- do not run numeric physical range validation
- do not show “Value null...” error

If a numeric marker has no readable value:
show:
“Value could not be read.”

Do not show:
“Value null is outside physically possible range.”

Do not save null numeric values.
