TASK 2 — NO-LABS STATE TRUTH
────────────────────

If the user has no confirmed labs:

Dashboard may say:
- “Upload your first lab PDF”
- “Meridian needs your first lab to build your biological snapshot.”

This is fine ONLY when no labs exist.

If labs exist:
- do NOT show upload-first-lab copy
- do NOT imply the user has no data

────────────────────
TASK 3 — LABS-SAVED / BASELINE-BUILDING STATE
────────────────────

When labs exist but Meridian does not have enough context for strong insights:

Use truthful baseline-building language.

Suggested direction:
- “Your lab snapshot is active.”
- “Meridian is building confidence as more lab history and context are added.”
- “Insights become more precise as trends, feedback, and additional signals accumulate.”

Avoid:
- pretending strong trends exist
- claiming a full baseline exists too early
- overpromising daily intelligence

────────────────────
TASK 4 — SAFE INSIGHT LANGUAGE
────────────────────

Review generated insight copy and fallback copy.

Problem example:
A B12 insight said something like:
“your body isn’t clearing it efficiently”

This sounds too causal/diagnostic.

Replace or sanitize unsafe language patterns.

Insight language should prefer:
- “may reflect”
- “could suggest”
- “is worth clarifying”
- “Meridian does not yet have enough context to determine why”
- “This signal should be interpreted alongside medications, supplementation, diet, and recent labs.”

Avoid:
- “your body isn’t clearing…”
- “this means…”
- “you have…”
- “caused by…”
- “because your…”
- treatment instructions
- supplement recommendations unless explicitly safe and non-medical

────────────────────
TASK 5 — API INSIGHT FALLBACK TRUTH
────────────────────

If Anthropic fails, returns invalid JSON, or insufficient data exists:

`/api/insight` should return valid JSON with truthful fallback state.

Fallback should not:
- invent a Golden Insight
- invent a trend
- imply certainty
- sound broken

Acceptable fallback:
- state: `labs_saved` or `insight_unavailable`
- message: “Your lab data is saved. Meridian is still building enough context for a stronger interpretation.”
- CTA: “Review lab results”

Do NOT return 500 for expected insufficient-context cases.
